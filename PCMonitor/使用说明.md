# 别墅安防串口报警监控

双击 [VillaSecurityMonitor.exe](VillaSecurityMonitor.exe) 即可打开 Windows 桌面程序，不需要安装 Python。程序会自动扫描 COM 口；连接后显示布防、红外、热敏和报警状态。报警开始会弹出通知并播放提示音，事件可导出 CSV。设备连续 3 秒没有发送有效数据时，界面显示“通信中断”，不会继续显示旧的安全状态。

## 第一次使用

1. 在 Keil 中打开上一层文件夹的 `VillaSecurity_STLink.uvprojx`，按 F7 编译，再按 Download 烧录。旧固件没有串口输出，必须重新烧录。
2. **断电接线**：STM32 的 **PA9** 接 CH340 模块的 **RXD**；STM32 的 **GND** 接 CH340 的 **GND**。这是单向状态传输。CH340 的 **TXD、VCC/5V/3.3V 均不接 STM32**；STM32 继续按原来的方式供电。不要将 CH340 的 5V 接到 STM32 的 3.3V 引脚。
3. 将 CH340 插入电脑 USB，给 STM32 上电。在 Windows“设备管理器 > 端口 (COM 和 LPT)”确认出现 COM 口。
4. 双击 `VillaSecurityMonitor.exe`；选对应 COM 口，点击“连接”。程序使用固定的 **115200 波特率、8 数据位、无校验、1 停止位**。
5. 屏幕出现“已撤防”或“已布防”表示收到数据。按 PA2 外置按键布防，再触发红外或热敏模块，电脑应显示“报警中”并记录事件。撤防后传感器变化仍会显示，但不会报警。

ST-LINK 下载器的 SWD 接口不能代替上述串口连接。CH340 只负责传送状态，程序运行时不需要在 Keil 中打开串口窗口；如果其他串口工具占用了同一个 COM 口，请先关闭它。

## 收不到数据时

- 软件没有显示 COM 口：检查 CH340 是否插入电脑、USB 线是否支持数据传输，以及 Windows 是否安装对应驱动。点击“刷新串口”。
- 已连接但显示“通信中断”：确认已烧录新版固件、STM32 正在运行，检查 **PA9 → RXD、GND → GND**。不要把 PA9 接到 CH340 的 TXD。
- 串口打开失败：可能被其他软件占用，关闭其他串口工具后再试。
- 软件显示报警但蜂鸣器不响：电脑已经收到报警状态，重点检查原有蜂鸣器的 5V、共地与 PB10 接线。

串口数据每 500 毫秒发送一次，格式为 `VS1,运行毫秒,布防,红外,热敏,报警`；状态变化时会立即发送。布尔字段只有 `0` 或 `1`。

电脑监控依赖 USB、电脑程序和 STM32 供电；它是课程演示系统，不能替代独立的住宅安防设备。
